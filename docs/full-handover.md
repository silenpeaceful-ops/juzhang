# 聚账：使用与继续开发说明

网站：https://juzhang-20261012.silkyharp4.chatgpt.site

## 首次使用
1. 在 Safari 打开网站，使用本人的 ChatGPT 账号登录。
2. 分享 → 添加到主屏幕，即可像 App 一样打开。
3. 先手动记一笔或在「接入」页粘贴一条消费通知，确认金额和渠道正确。
4. 「接入」页可获取快捷指令专属地址与请求头。先配置银行交易短信自动化，将交易正文作为 text 发送。微信、支付宝通知是否能作为输入，必须在实际系统中验证，不能视为已经支持。只有成功转发且包含可识别金额的消费会自动入账。
5. 「每日清单」选择本人微信接收服务，填写 SCT SendKey、PushPlus Token，或企业微信群机器人地址。先手动测试，再开启每天自动发送。
6. 每天北京时间 21:00 发送昨天完整自然日的清单。未登录初始化、未配置接收通道或未启用时不发送。

## 删除自己添加的账单
在「账单」页或概览的最近账单，点对应记录旁的「删除」，核对商户和金额后点「确认删除」。误点可选择「保留账单」；完成后可在提示条点「撤销」。已删除记录不计入汇总、后续每日清单及导出。已发送到微信的历史消息不会因此收回。

## 功能与边界
统一汇总微信、支付宝和银行卡消费；消费、退款和资金转移分开；相近时间的跨渠道同额记录放入待核对；CSV 导入和导出；完整逐笔清单。自动采集需实际检查快捷指令能否读取通知正文；未触发、无金额或未成功转发的交易需官方 CSV 补账。

账本属于本人私有网站，保存于服务器数据库。接收渠道通过所选第三方服务推送到本人微信；后台解析和生成清单不调用大语言模型。请勿公开分享带请求头密钥的快捷指令。
