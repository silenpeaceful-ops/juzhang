# 聚账美化方向

用户请求：用 frontend-design 和 impeccable 美化聚账。已确认外观：苹果风格，白灰、简洁。

本轮保留原有产品结构与所有功能，以已有四页做视觉精修；直接在代码中实现，不为产品界面生成图片。

色彩：轻灰背景 #f5f5f7、白色表面 #fff、深灰主文字 #1d1d1f、辅助灰 #636366、分隔灰 #d9d9de；#0068d9仅为主操作/选中/focus。红色仅删除、绿色仅收入等状态。
字体：苹果系统sans与PingFang SC，金额使用tabular numerals；手机输入16px、辅助文字至少12px，层级由字号/字重与间距构成。
布局：白色分组表面，手机保持单列图表和渠道入口；金额右对齐，交易操作在明确触点内；桌面为固定侧栏与居中内容。
原则：标题不加装饰眉题和句点；移除摘要装饰环；不用渐变、照片、背景纹理或入场动画。现有图表是实际账本数据，读数与标签完整。

第一屏：标题+记一笔、本月支出、收入/今日支出/待核对；每个交易删除可找到，误删可撤销。
验证：390px手机、768px中间尺寸、1440px桌面，四页+手动CRUD/删除/撤销本地合成数据；不删除用户实际账单、不发送真实微信推送。
